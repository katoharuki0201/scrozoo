# Scrozoo 要件定義

## 1. 基本情報

- 企画: TechJam 2026
- チーム: チームB
- サービス名（仮）: Scrozoo
- メンバー: 加藤晴快、勝野鉱治、鈴木晟琥、塩谷咲弥、中元響介、千葉星梧

## 2. 目的とコンセプト

### コンセプト

動物の日常を毎日楽しみにしながら、応援できる推し活動画サービス。

### 解決する課題

動物園側:

- 入園料が天候や立地に左右される
- 飼料代、光熱費などの負担が増えている
- SNS 運用や広報に割ける人員・時間が不足している
- 継続的なオンライン収益源が少ない

利用者側:

- 忙しさや距離のため、頻繁に動物園へ行けない
- 推し動物の日常や成長を継続して見守りたい
- 動物園を応援したいが、従来の寄付には敷居を感じる
- 子どもに動物の生態や命の大切さを学ばせたい

### 提供価値

- 飼育員が撮影した動物の日常をショート動画で届ける
- 無料ユーザーは冒頭5秒、有料サポーターは応援中の動物園の動画をフル視聴できる
- 月額支援と投げ銭付きコメントにより、支援を身近な体験にする
- 現地 QR コードを使い、来園者だけが写真を投稿できる
- オンラインで知る、応援する、現地で会う、さらに応援する循環をつくる

## 3. 対象

### 応援される対象

- 地方・公立の動物園
- 動物園で働く飼育員
- 動物園で飼育されている動物

対象の活動は、動物の保護・飼育、種の保存、環境エンリッチメント、教育・展示活動とする。

### 主な利用者

#### 20〜30代の推し活層

- SNS やショート動画を日常的に利用する
- 好きな動物やキャラクターを応援する文化に親しんでいる
- 通勤・通学、就寝前などの短い時間に利用する

#### 情操教育に関心のある親子層

- 小学生以下の子どもを持つ保護者
- 安心して見せられる学習性のあるコンテンツを求めている
- 家庭での団らん・学習時間や休日の来園時に利用する

## 4. 利用者種別と権限

| 機能 | 未ログイン | 一般ユーザー | 有料サポーター | 投稿者 |
| --- | --- | --- | --- | --- |
| 動画の冒頭視聴 | 可 | 可 | 可 | 可 |
| 応援中の動物園の動画フル視聴 | 不可 | 不可 | 加入中のみ可 | 自身の投稿は可 |
| お気に入り | 不可 | 可 | 可 | 可 |
| 通常コメント | 不可 | 可 | 可 | 可 |
| 投げ銭付きコメント | 不可 | 可 | 可 | 対象外 |
| ギャラリー閲覧 | 可 | 可 | 可 | 可 |
| 現地ギャラリー投稿 | 不可 | QR 認証後に可 | QR 認証後に可 | QR 認証後に可 |
| 動画投稿・管理 | 不可 | 不可 | 不可 | 可 |
| サポーター一覧 | 不可 | 不可 | 不可 | 可 |

投稿者アカウントと応援プランは動物園単位とする。動画とギャラリーには対象動物を表示用メタデータとして紐づけられる。

## 5. 機能要件

要件 ID は実装・テスト時の参照用とする。

### 5.1 アカウント・認証

- `AUTH-01`: ユーザー名、メールアドレス、パスワードで一般ユーザーを登録できる
- `AUTH-02`: メールアドレスとパスワードでログインできる
- `AUTH-03`: ログアウトできる
- `AUTH-04`: 一般ユーザーと投稿者の権限を区別できる
- `AUTH-05`: パスワードを安全に保存し、再設定できる
- `AUTH-06`: Google アカウントで登録・ログインできる

### 5.2 プロフィール

- `USER-01`: 本人用マイページに名前、メールアドレス、アイコン、自己紹介を表示できる
- `USER-02`: メールアドレス以外のプロフィール項目を編集できる
- `USER-03`: 自分が投稿したギャラリー写真を一覧表示できる
- `USER-04`: ユーザー名、アイコン、自己紹介、公開ギャラリーは全ユーザーが閲覧できる
- `USER-05`: メールアドレスとサポートログは本人以外に表示しない

### 5.3 動物園・動物・投稿者

- `PUBLISHER-01`: 動物園を1つの投稿者アカウントとして管理する
- `PUBLISHER-02`: 投稿者ページに動物園のプロフィールと SNS リンクを表示する
- `PUBLISHER-03`: 投稿者ページで「投稿動画」「サポーターギャラリー」を切り替えられる
- `ANIMAL-01`: 動物と所属動物園を紐づけて管理できる
- `ANIMAL-02`: 動画に対象動物を紐づけ、検索・絞り込みに使用できる
- `ANIMAL-03`: 応援プランと動画の閲覧権限を動物園単位で管理できる

### 5.4 動画

- `VIDEO-01`: 投稿者は動物のショート動画を投稿できる
- `VIDEO-02`: 動画に投稿者、対象動物、説明、投稿日を紐づけられる
- `VIDEO-03`: 未加入者には動画の冒頭5秒のみを再生する
- `VIDEO-04`: 応援中の動物園が投稿した動画はフル再生できる
- `VIDEO-05`: 動画詳細から投稿者ページへ移動できる
- `VIDEO-06`: 動画をお気に入りに追加・解除できる
- `VIDEO-07`: 動画に通常コメントを投稿・閲覧できる
- `VIDEO-08`: 動物名、動物園名、動物種、タグで動画を検索・一覧表示できる
- `VIDEO-09`: 投稿者は自身の動画を管理できる
- `VIDEO-10`: Web アプリ内で動画を撮影できる
- `VIDEO-11`: カメラ非対応端末向けに動画ファイル選択も提供する

### 5.5 応援プラン・決済

- `PAY-01`: 一般ユーザーは動物園単位の月額応援プランに加入できる
- `PAY-02`: 月額500円の「お試しサポータープラン」1種類を扱える
- `PAY-03`: 加入者は対象動物園の動画をフル視聴できる
- `PAY-04`: 複数の動物園を応援する場合、動物園ごとに加入する
- `PAY-05`: Stripe Sandbox とテスト API キーのみを使い、実際の請求なしで決済成功・失敗を再現する
- `PAY-06`: 加入日を契約開始日とし、1か月ごとに更新する
- `PAY-07`: 解約後も支払済み期間の末日まで閲覧権限を維持し、日割り計算と返金は行わない
- `PAY-08`: Stripe Webhook の署名を検証し、テスト決済の成功・失敗・解約を閲覧権限へ反映する
- `PAY-09`: Stripe の同一イベント ID を二重反映しない

### 5.6 投げ銭

- `TIP-01`: 動画に100円〜3,000円の単発投げ銭付きコメントを投稿できる
- `TIP-02`: 投げ銭額、日時、対象動画、対象動物、対象投稿者を記録する
- `TIP-03`: ログイン済みユーザーはプラン加入状態にかかわらず投げ銭できる
- `TIP-04`: Stripe のテスト決済が成功した場合のみ投げ銭コメントを確定する

### 5.7 お気に入り・サポートログ

- `FAVORITE-01`: お気に入りに追加した動画を一覧表示できる
- `LOG-01`: 月額プランへの加入履歴を日付順に表示できる
- `LOG-02`: 投げ銭の金額と履歴を日付順に表示できる
- `LOG-03`: 履歴から支援先の動物園と対象動画を確認できる

### 5.8 現地 QR・サポーターギャラリー

- `GALLERY-01`: アプリ内カメラまたは端末の標準カメラで園内 QR コードを読み込める
- `GALLERY-02`: 有効な QR 認証後、写真の撮影または選択へ進める
- `GALLERY-03`: タイトルと画像を設定してギャラリーへ投稿できる
- `GALLERY-04`: 投稿を QR の対象動物園と、必要に応じて対象動物へ紐づけられる
- `GALLERY-05`: ギャラリー投稿者と投稿日時を記録する
- `GALLERY-06`: QR 検証成功時から2時間、対象動物園への投稿を許可する
- `GALLERY-07`: QR URL の署名検証と投稿レート制限を行う
- `GALLERY-08`: ギャラリー投稿は即時公開し、全ユーザーが閲覧できる

### 5.9 投稿者向け管理

- `CREATOR-01`: 自身に紐づく動物の動画を作成・管理できる
- `CREATOR-02`: 応援プラン加入者と投げ銭利用者をサポーターとして一覧表示できる
- `CREATOR-03`: 一覧にサポーターのユーザー名とアイコンを表示し、公開プロフィールへ遷移できる
- `CREATOR-04`: 自身の投稿者ページと SNS リンクを管理できる
- `CREATOR-05`: 自身の動物園に掲示する無期限の来園 QR コードを表示し、PNG で保存できる

### 5.10 MVP 対象外

- サポーターチャットは MVP の機能要件に含めない

## 6. 料金・収益ルール

### 料金

- お試しサポータープラン: 動物園ごとに月額500円
- 単発投げ銭: 100円〜3,000円
- 支払者: 原則として利用者本人。親子利用では保護者が契約・支払いを行う

### 分配

- 動物園への還元: 利用者支払額の80％
- スパイラル東海の収益: 利用者支払額の20％
- 分配率は事業企画上の想定であり、実際の決済・精算は行わない

月額500円の場合、企画上は400円を動物園へ還元し、100円をスパイラル東海の収益とする。

### 売上想定

| 指標 | 想定値 |
| --- | ---: |
| サービス開始時の有料利用者 | 100人 |
| 1年後の有料利用者 | 1,000人 |
| 1人あたり平均月額 | 800円 |
| 1年後の月間売上 | 800,000円 |
| 年間売上 | 9,600,000円 |
| 年間プラットフォーム収益 | 1,920,000円 |
| 年間動物園還元額 | 7,680,000円 |

単発投げ銭は上記試算に含めない。

## 7. 非機能要件

### セキュリティ・プライバシー

- 通信を HTTPS で暗号化する
- パスワードを平文保存しない
- 認証、認可、入力検証、CSRF・XSS 対策を行う
- 個人情報、モック課金情報、投稿データへのアクセスを権限で制御する
- モック課金の状態変更を記録する

### 可用性・整合性

- 動画・画像アップロード失敗時に再試行または明確なエラー表示を行う
- データのバックアップと復旧手順を用意する

### 性能・ユーザビリティ

- スマートフォンを主対象とするレスポンシブ Web UI とする
- iOS Safari と Android Chrome でカメラ撮影、QR 読み取り、動画再生を確認する
- モバイル回線でも動画の再生開始を待たせすぎない
- 動画・画像を端末や回線に応じた形式・サイズで配信する
- キーボード操作、代替テキスト、十分な色コントラストに配慮する

### 法務・運用

- 利用規約、プライバシーポリシー、特定商取引法に基づく表記を用意する
- 写真・動画の肖像権、著作権、投稿権限を規約で明確にする
- 未成年者の利用および保護者による課金の扱いを定める
- 解約、退会、データ保持の方針を利用者に表示する

## 8. 成功指標候補

- 有料利用者数、無料から有料への転換率
- 応援プランの継続率・解約率
- 動物園ごとの支援額
- 動画の視聴開始率、完視聴率、再訪率
- 投げ銭件数と平均額
- QR 認証数、ギャラリー投稿数、来園転換の推定値
- 投稿者ごとの動画更新頻度
