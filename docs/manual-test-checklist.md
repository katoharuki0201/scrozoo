# MVP 手動テストチェックリスト

## 1. テスト前の準備

### 共通

- [ ] Chrome または Safari の開発者ツールを開き、Console に未処理例外が出ていないことを確認する
- [ ] スマートフォン幅（390〜430px）とデスクトップ幅の両方で表示する
- [ ] カメラ、画像、動画を扱う確認は HTTPS または `localhost` で行う
- [ ] Payment Linkへの遷移では契約、投げ銭コメント、応援目標が更新されないことを前提とする

### MSW モード

- [ ] `apps/web/.env` の `VITE_ENABLE_MOCKS=true` を確認する
- [ ] Webだけを起動し、APIサーバーを起動していない状態でも操作できることを確認する
- [ ] 一般ユーザー: `mock.user@example.com` / `password123`
- [ ] 投稿者: `creator@scrozoo.jp` / `password123`
- [ ] 管理者: `admin@scrozoo.jp` / `admin1234`

### 実APIモード

- [ ] `VITE_ENABLE_MOCKS=false` にする
- [ ] APIの環境変数、Turso、公開・非公開R2、R2 CORSを設定する（`apps/api` で `bun run r2:cors`）
- [ ] DBマイグレーションを適用する
- [ ] `bun run db:seed:dev-accounts` または運用データで管理者・投稿者を用意する
- [ ] 投稿者の動物園に、投稿対象として選べる有効な動物を1件以上登録する
- [ ] `GET /api/health` が `200`、`GET /api/ready` が `200` になる

## 2. ゲスト・認証

### ユーザーストーリー: 新しい利用者として登録する

- [ ] 未ログインで保護された画面を開くとログイン画面へ移動する
- [ ] 登録画面でユーザー名、メール、8文字以上のパスワードを入力できる
- [ ] 不正なメール、短いパスワード、空の名前では送信できない
- [ ] 正常に登録するとログイン状態になり、一般ユーザー画面へ移動する
- [ ] 同じメールアドレスの再登録はエラーになる

### ユーザーストーリー: 既存利用者としてログインする

- [ ] 正しいメールとパスワードでログインできる
- [ ] 不正な資格情報ではエラーが表示される
- [ ] Googleログインを開始できる
- [ ] ページを再読み込みしてもセッションが復元される
- [ ] ログアウトすると保護画面へ戻れなくなる
- [ ] 一般ユーザー、投稿者、管理者の画面がロールごとに分離される

## 3. 一般ユーザーの動画体験

### ユーザーストーリー: 動画を探して視聴する

- [ ] ホームに公開動画が表示される
- [ ] 動画、動物園名、説明、タグ、いいね数、コメント数が表示される
- [ ] 未加入の動物園では5秒プレビューが使われる
- [ ] 有効期間内の契約がある動物園ではフル動画URLが使われる
- [ ] 解約予定でも契約期間内ならフル動画を視聴できる
- [ ] 契約期間終了後はフル動画を視聴できない
- [ ] 動物園アイコンから対象動物園ページへ移動できる

### ユーザーストーリー: 動画を検索する

- [ ] 動物名で検索できる
- [ ] 動物種で検索できる
- [ ] 動物園名で検索できる
- [ ] タグで検索できる
- [ ] 新着順、古い順、人気順を切り替えられる
- [ ] 該当なしの場合に空状態が表示される

### ユーザーストーリー: お気に入りを管理する

- [ ] 動画をお気に入りへ追加できる
- [ ] 同じ操作でお気に入りを解除できる
- [ ] お気に入り一覧へ反映される
- [ ] ページ移動後も表示状態が一致する

### ユーザーストーリー: コメントする

- [ ] 通常コメントを投稿できる
- [ ] 空文字と200文字超過を拒否する
- [ ] 投稿したコメントが一覧先頭へ表示される
- [ ] 契約中ユーザーのコメントにサポーター表示が付く

### ユーザーストーリー: 投げ銭導線を利用する

- [ ] 100円、500円、1,000円、3,000円を選べる
- [ ] 応援コメントを入力してStripeテスト Payment Linkへ移動する
- [ ] 実際の請求が発生しない旨が表示される
- [ ] 戻った後、投げ銭コメントや金額がDB・画面へ自動反映されていない
- [ ] 投稿者アカウントでは投げ銭APIが `403` になる

## 4. 動物園・プロフィール・契約

### ユーザーストーリー: 動物園を確認・応援する

- [ ] 動物園ページに名前、説明、動画、サポーターギャラリーが表示される
- [ ] 動画タブとギャラリータブを切り替えられる
- [ ] 月額500円の応援案内を開ける
- [ ] 応援操作でStripeテスト Payment Linkへ移動する
- [ ] Payment Linkから戻っても契約が自動作成されない

### ユーザーストーリー: 自分の情報を管理する

- [ ] マイページに名前、自己紹介、投稿ギャラリーが表示される
- [ ] ユーザー名と自己紹介を編集できる
- [ ] メールアドレスは表示されるが編集できない
- [ ] 契約プラン一覧にDB登録済みの加入中・解約予定プランが表示される
- [ ] プラン解約操作で「解約予定」へ変わる

### ユーザーストーリー: 公開プロフィールを見る

- [ ] `/users/:userId` を未ログインでも開ける
- [ ] 名前、アイコン、自己紹介、公開ギャラリーが表示される
- [ ] メールアドレスと契約情報は表示されない
- [ ] 存在しないユーザーではエラー画面になる

## 5. QR・来園ギャラリー

### ユーザーストーリー: 投稿者として来園QRを用意する

- [ ] 投稿者マイページから「来園QRコード」を開ける
- [ ] 自分の動物園名とQR画像が表示される
- [ ] 有効期限なしと表示される
- [ ] 再読み込みしても同じQR内容になる
- [ ] PNGを保存でき、保存画像をQRリーダーで読み取れる

### ユーザーストーリー: 来園者として写真を投稿する

- [ ] アプリ内カメラでQRを読み取れる
- [ ] 端末標準カメラでQR URLを開ける
- [ ] 無効なQRでは投稿画面へ進めない
- [ ] QR検証後、投稿権限の対象動物園が表示される
- [ ] カメラ撮影と画像ライブラリ選択の両方を使える
- [ ] 画像を確認して投稿できる
- [ ] 同じ2時間の投稿権限で複数枚投稿できる
- [ ] 投稿後、動物園ギャラリーと自分のマイギャラリーへ反映される
- [ ] 2時間を過ぎた投稿権限は拒否される

## 6. 投稿者機能

### ユーザーストーリー: 動画を投稿する

- [ ] 投稿者ナビゲーションにマイページ、投稿作成、サポーターが表示される
- [ ] 投稿対象の動物を明示的に選択できる
- [ ] 動物未選択では投稿できない
- [ ] カメラで動画を撮影できる
- [ ] 端末から動画ファイルを選択できる
- [ ] MP4、WebM、MOVを選択できる
- [ ] 60秒超過または200MB超過を拒否する
- [ ] キャプションと最大5件のタグを設定できる
- [ ] アップロード進捗が表示される
- [ ] アップロードをキャンセル・再試行できる
- [ ] 投稿成功後、投稿者マイページへ動画が追加される
- [ ] 選択した動物へ正しく紐づく

### ユーザーストーリー: 応援目標を管理する

- [ ] 応援目標のタイトル、金額、期限を登録できる
- [ ] 登録済み目標を更新できる
- [ ] 目標を削除できる
- [ ] 動物園ページに進捗が表示される
- [ ] Payment Link操作では現在金額が自動加算されない

### ユーザーストーリー: サポーターを確認する

- [ ] 有効期間内のプラン加入者だけが一覧に表示される
- [ ] 名前、アイコン、加入日、次回更新日または利用終了日が表示される
- [ ] サポーター数と月間支援額が一致する
- [ ] サポーターを選ぶと公開プロフィールへ移動する
- [ ] 公開プロフィールにメールアドレスや契約情報が表示されない

## 7. 管理者機能

### ユーザーストーリー: サービス状況を管理する

- [ ] `/admin/login` から管理者だけがログインできる
- [ ] ダッシュボードのユーザー数、投稿者数、契約数、収益表示を確認できる
- [ ] ユーザー一覧の絞り込みと加入先への遷移が動く
- [ ] 契約者一覧の絞り込みが動く
- [ ] 収益画面の月別グラフと内訳が表示される

### ユーザーストーリー: 投稿者アカウントを管理する

- [ ] 動物園名、担当者名、メール、初期パスワードで投稿者を発行できる
- [ ] 重複メールや不正入力を拒否する
- [ ] 発行直後に資格情報を一度確認・コピーできる
- [ ] 投稿者を停止すると既存セッションが失効する
- [ ] 停止中の投稿者はログイン・投稿者APIを利用できない
- [ ] 再有効化後に再ログインできる
- [ ] 管理者ログアウト後は管理画面へ戻れない

## 8. エラー・表示・端末確認

- [ ] API停止時に無限ローディングせずエラーと再試行操作が表示される
- [ ] 401ではログイン導線、403では権限不足、404では対象なしとして扱われる
- [ ] 二重送信中はボタンが無効になる
- [ ] 長い名前、説明、コメントでもレイアウトが崩れない
- [ ] キーボードだけで主要フォームとダイアログを操作できる
- [ ] 画像に必要な代替テキストまたは装飾画像指定がある
- [ ] iOS Safariでログイン、動画、カメラ、QR、画像投稿を確認する
- [ ] Android Chromeでログイン、動画、カメラ、QR、画像投稿を確認する
- [ ] Consoleに秘密情報、Cookie、署名付きR2 URLが不用意に出力されない

## 9. 意図的なMVP制約

- [ ] Stripe API、Webhook、決済結果反映を行わないことを確認した
- [ ] Payment Linkだけでは契約・投げ銭・コメント・応援目標を更新しないことを確認した
- [ ] サポーターチャットが画面・APIに存在しないことを確認した
- [ ] QR失効・再生成、位置情報による園内判定を実装していないことを確認した
- [ ] 自動E2E、CI、追加レート制限をMVP対象外として了承した
- [ ] Webバンドルサイズ警告を `docs/quality-notes.md` の継続課題として確認した
