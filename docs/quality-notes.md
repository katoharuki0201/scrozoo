# MVP 品質メモ

## 今回の対象外

- 自動E2EテストとCIワークフローは導入せず、最終確認は手動で行う。
- QR・投稿APIの追加レート制限、法務文書、バックアップ運用はMVP後に検討する。
- Stripe API・Webhook・決済結果反映は実装しない。

## 継続確認事項

- Webの本番ビルドではメインJavaScriptが約588KBとなり、Viteの500KB警告が出る。MVP後に画面単位の遅延読み込みを検討する。
- APIの開発依存 `drizzle-kit` が参照する旧版 `esbuild` に moderate の既知脆弱性がある。本番ランタイム依存ではないが、互換性を確認して更新する。
- APIエラー形式、入力検証、一覧ページングは主要導線から順次共通化する。
